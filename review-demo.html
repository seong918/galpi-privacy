Local photo import: foreground service demonstration

This recording shows Galpi's local import worker processing 600 synthetic images on an Android emulator. No personal photos or account data are used.

Open or download the video (MP4)

  1. A paused import begins when the user selects 계속하기 (Resume).
  2. The foreground service displays an ongoing notification titled 진행 중인 작업 (Ongoing tasks). The app shows item counts and progress.
  3. The user can pause and resume the import. Progress is retained.
  4. The import completes with 600 / 600 images processed.

The dataSync foreground service supports user-initiated local imports, library scans and backup export. It keeps lengthy local operations visible and lets users inspect, pause or cancel them from the task screen. No remote server is involved in this demonstration.

Recorded October 3, 2026, using an emulator QA build with the same foreground worker implementation as release 0.1.0. Test fixtures are prepared by the QA harness; subsequent resume/pause controls use the app UI. Older synthetic task history may be visible below the current task.
