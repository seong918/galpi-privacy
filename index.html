갈피 개인정보처리방침

운영자: FAN BURSTER Studio · 시행일: 2026년 10월 2일
대상 앱: 갈피 — 스크린샷 정리 / Galpi · com.fanburster.galpi

갈피는 사용자가 선택하거나 접근을 허용한 스크린샷을 정리하고 다시 찾는 Android 앱입니다. 이 방침은 앱의 사진 접근, 기기 내 처리, 사용자가 선택하는 외부 전송, 포함된 SDK 및 고객지원 과정의 데이터 처리를 설명합니다.

1. 기기에 저장하는 자료

앱은 접근을 허용한 사진과 파일의 내용, 파일 이름·경로·크기·날짜, 텍스트 인식 결과, 서랍·태그·제목·메모, 정리 상태·알림·사용자 설정을 기기에 저장합니다. 보관·자르기를 실행하면 앱 내부에 이미지 사본이 만들어질 수 있습니다. 의미 검색을 사용하면 텍스트를 바탕으로 한 검색 색인도 기기에 저장합니다. 갈피는 자체 회원가입이나 로그인 계정을 요구하지 않습니다.

2. 사진 및 알림 권한

사진 접근 권한은 스크린샷을 찾고 읽거나 정리할 때 사용합니다. Android 버전에 따라 전체 사진 접근, 선택한 사진 접근 또는 시스템 사진 선택기를 사용할 수 있습니다. 알림 권한은 사용자가 켠 정리 알림 등에 사용합니다. 권한은 Android 앱 설정에서 변경할 수 있으며, 거부하면 관련 기능이 제한될 수 있습니다. 원본 사진의 휴지통 이동·복원 등은 Android가 요구하는 승인 절차를 따릅니다.

3. 기기 내 사진·텍스트 처리

사진의 텍스트 인식은 Google ML Kit를 사용해 기기에서 처리합니다. ML Kit는 입력 이미지와 인식 결과를 Google 서버에 전송하지 않는다고 안내합니다. 갈피도 사진·인식 텍스트·메모·검색어를 자체 분석 서버나 광고 요청에 포함하지 않습니다. 다만 아래 SDK 진단 정보 및 사용자가 직접 선택한 공유·백업·동기화는 별도입니다.

4. Google ML Kit의 진단 정보

Google ML Kit는 기기 제조사·모델·운영체제, 앱 패키지와 버전, 설치별 식별자, 처리 지연·오류·기능 사용 이벤트, 입력 형식·해상도·크기 등의 진단 및 사용 지표를 Google에 전송할 수 있습니다. 이는 사진 내용 자체나 인식된 문장의 전송과 구별됩니다. Google은 해당 지표를 성능 측정, 유지·개선 및 오용 방지 등에 사용하며 HTTPS로 전송한다고 안내합니다. Google의 보관 및 처리 기준은 아래 문서를 참고하세요.

  • ML Kit 이용약관 및 개인정보 안내
  • ML Kit 데이터 공개 안내
  • Google 개인정보처리방침

5. 선택적 백업·공유·동기화

백업 파일에는 선택한 범위에 따라 사진 사본, 인식 텍스트, 서랍·태그·메모 및 설정이 포함될 수 있습니다. 사용자가 시스템 파일 선택기로 저장 위치를 고르면 해당 저장소 제공자의 처리가 적용됩니다. 공유 기능은 사용자가 고른 앱에 선택한 자료를 전달합니다.

원격 동기화는 기본적으로 꺼져 있습니다. 사용자가 직접 HTTPS 서버 주소와 필요한 인증 정보를 설정하고 켜면 사진·메타데이터 등이 포함된 백업을 해당 서버와 주고받습니다. 연결 정보는 기기에서 Android Keystore를 이용해 보호합니다. 전송 구간은 HTTPS를 사용하지만 백업 파일 자체가 암호화되어 있다고 보장하지 않습니다. 서버 운영자의 접근·보관·삭제 정책을 확인하고 신뢰할 수 있는 저장소를 선택하세요. 동기화를 끄거나 앱을 삭제해도 이미 외부에 저장한 백업은 자동 삭제되지 않습니다.

6. 의미 검색 모델 다운로드

사용자가 의미 검색 모델 다운로드를 선택하면 Hugging Face에서 공개 모델 파일을 내려받습니다. 이 과정에서 호스팅 제공자는 IP 주소 등 통상적인 접속 정보를 처리할 수 있습니다. 검색어와 사진·인식 텍스트는 모델 다운로드 요청에 포함하지 않으며, 다운로드 후 검색 계산은 기기에서 수행합니다. Hugging Face 개인정보처리방침

7. 광고

갈피에는 Google Mobile Ads 및 동의 관리 SDK가 포함되어 있습니다. 현재 0.1.0 초기 출시 구성은 상용 광고 식별자가 설정되지 않아 광고를 요청하지 않습니다. 광고가 활성화된 버전에서는 필요한 동의·선택 절차에 따라 광고가 표시될 수 있으며, Google 광고 SDK는 IP 주소에 따른 대략적 위치, 광고/앱 상호작용, 진단 정보, 광고 ID·앱 세트 ID 등의 식별자를 광고·분석·부정행위 방지 목적으로 처리할 수 있습니다. 사진·인식 텍스트·메모·검색어는 광고 SDK에 제공하지 않습니다. 광고 구성이 바뀌면 스토어 데이터 보안 정보와 이 안내를 함께 갱신합니다. Google Mobile Ads 데이터 처리 안내

8. 보관과 삭제

기기 내 자료는 사용자가 앱에서 정리하거나 삭제할 때까지 보관됩니다. 설정의 데이터 관리에서 정리 정보 초기화와 앱 보관 사본 삭제 기능을 사용할 수 있습니다. Android에서 앱 저장공간을 삭제하거나 앱을 제거하면 앱의 전용 저장공간에 있는 자료가 삭제됩니다. 갤러리 원본, 다른 앱으로 공유한 자료, 외부 저장소의 백업은 별도로 관리해야 합니다. Google 등 외부 서비스가 처리하는 진단 정보는 해당 서비스의 방침이 적용되며 갈피 운영자가 직접 삭제할 수 있는 자료와 구별됩니다.

9. 고객지원 및 권리 행사

문의할 경우 이메일 주소, 문의 내용 및 사용자가 직접 첨부한 자료를 문제 해결과 답변 목적으로 처리합니다. 민감한 사진이나 비밀번호는 보내지 마세요. 문의 자료는 처리에 필요한 기간 동안 보관하며, 삭제 요청 또는 법령상 보관 의무가 있으면 그에 따라 처리합니다. 열람·정정·삭제 등 개인정보 관련 요청은 furster.official@gmail.com으로 연락할 수 있습니다. 기기에만 있는 사진·메모는 운영자가 원격으로 열람하거나 삭제할 수 없습니다.

10. 아동, 국외 서비스 및 방침 변경

갈피는 일반 사용자의 개인자료 정리 도구로, 아동을 주 대상으로 설계하지 않았습니다. Google, GitHub, Hugging Face 또는 사용자가 선택한 저장소 등 외부 서비스를 이용하는 과정에서 각 제공자의 처리 위치와 정책에 따라 데이터가 다른 국가에서 처리될 수 있습니다. 이 웹사이트는 GitHub Pages로 제공되며 별도의 분석 도구나 광고 쿠키를 추가하지 않습니다. 서비스 및 법령 변경에 따라 방침을 수정할 경우 이 페이지의 시행일과 내용을 갱신합니다.
